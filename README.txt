VAREN ESTATE — VELTOWEB Concept Project

실행 방법
1. ZIP 압축을 해제합니다.
2. index.html을 더블클릭합니다.
3. 별도 설치, npm, 서버 실행이 필요하지 않습니다.

GitHub Pages
- varen-estate 폴더의 내용을 Repository에 그대로 업로드하면 됩니다.
- 모든 경로는 상대 경로로 구성되어 있습니다.

구성
- index.html / properties.html / property.html / areas.html / services.html / sell.html / about.html / contact.html / 404.html
- css/ / js/ / images/

주의

- 표시되는 매물, 연락처, 주소, Advisor 정보는 콘셉트용입니다.
